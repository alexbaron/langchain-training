# LangChain Training

Projet d'apprentissage de LangChain, LangGraph et Ollama.

Objectifs :

- Comprendre les LLM
- Construire un RAG
- Utiliser des outils (Tool Calling)
- Développer des agents
- Construire des workflows multi-agents

Stack :

- (Tauri)
- FastAPI
- LangChain
- LangGraph
- Ollama
- Qwen3
- ChromaDB

## Progression

- [x] Tauri (obsidian parser)
- [x] FastAPI
- [x] Connexion Ollama
- [ ] Prompt Templates
- [ ] RAG
- [ ] ChromaDB
- [ ] Tool Calling
- [ ] Agents
- [ ] LangGraph
